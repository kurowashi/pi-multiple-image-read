# ADR 0009: ラベルの番号は角括弧で囲む（`[5] 1234`）

## 状態

有効。[ADR 0008](0008-numbered-labels-slice-layout.md) のラベル表記（`番号 ファイル名`）を置き換えます。

## 状況

- ADR 0008 は、ラベルを `番号 ファイル名` で描くとしていました。
- 検証（6枚の合成画像、Noto Sans CJK JP 環境）で、番号と名前の境目が読めないことを確認しました。`5 1234` は `51234` に、`3 10` は `310` に、`4 12_12` は `412_12` に読めます。
- ファイル名が数字で始まるのは普通です（写真の連番、日付形式など）。実例7枚のうち2枚（`2025.8.23_…`）は数字で始まります。

## 決定

ラベルを `[番号] ファイル名` の形で描きます。名前が描けないときは `[番号]` だけを描きます。

- 表記は `labelText`（`src/labels.ts`）が作ります。テストは `test/unit/labels.test.ts` です。
- 返答テキストの番号は、従来どおり `番号. パス` です。ラベルの番号と同じ値を使います。

## 理由

- 角括弧は、番号の終わりを画像の中で示します。名前が数字で始まっても、番号と混ざりません。
- 角括弧は ASCII なので、CJK フォントがない環境でも番号は描けます（`canDrawLabel` の対象外）。
- 返答テキストのパスと同じ番号を、ラベルでも同じ形で描きます。

## 却下した代替

- **`#5 1234`**: 番号の前に記号を置くだけで、番号の終わりは示せません。`5 1234` と同じく、名前の先頭と混ざる余地が残ります。
- **番号を塗りつぶした枠に入れる**: 最も見分けやすいですが、描画コードが増え、枠の幅が番号の桁数で変わります。実装の複雑さに対して、角括弧で足りると判断しました。
- **番号を名前の後ろに置く（`1234 [5]`）**: 名前の末尾が切れると番号も切れます。切れた名前では番号が読めなくなるため却下しました。

## 未検証の点

- 角括弧の表記を、実際のモデルが番号として読むかは測定していません（`docs/manual-checks.md` の項目 7）。
